# Telegram Bot для трекера ссылок (LinkTracker)

## 📌 Описание проекта
Интерфейсный Telegram-бот на Python для взаимодействия пользователей с системой мониторинга обновлений на внешних ресурсах (GitHub, StackOverflow).

## 🛠 Технологии и реализация
* **Язык:** Python
* **Архитектура:** Клиентское приложение, взаимодействующее со скраппер-сервером через REST API.
* **Что использовано:** Асинхронный фреймворк для Telegram-ботов, HTTP-клиент (`httpx`), переменные окружения (`python-dotenv`).
* **Изученные инструменты:**
  * Разработка ботов с использованием современных библиотек.
  * Асинхронные сетевые запросы и обработка ошибок API.
  * Написание юнит и интеграционных тестов (`pytest`).

## 🚀 Инструкция по запуску
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Настройте файл `.env`, добавив токен Telegram-бота.
3. Запуск бота:
   ```bash
   python -m src.main
   ```
4. Запуск тестов:
   ```bash
   pytest
   ```
