# LinkTracker — Интеллектуальный агрегатор уведомлений

## 📌 Описание проекта
**LinkTracker** — это распределенная система мониторинга и агрегации обновлений с различных внешних ресурсов (GitHub, StackOverflow) с доставкой уведомлений пользователям через Telegram-бота. 

Проект спроектирован по микросервисной архитектуре и состоит из двух основных сервисов:
1. **`project-bot-service`** — клиентский сервис (Telegram-бот), отвечающий за взаимодействие с пользователем, регистрацию ссылок и отображение подписок.
2. **`project-scrapper-service`** — бэкенд-сервис, отвечающий за периодический опрос внешних API, хранение данных в реляционной базе данных и рассылку уведомлений.

---

## 🏗 Архитектура и стек технологий

### 1. Сервис Скраппера (`project-scrapper-service`)
Ядро бэкенда и бизнес-логики:
* **Фреймворк:** FastAPI (высокопроизводительный асинхронный REST API).
* **База данных и ORM:** PostgreSQL, SQLAlchemy, Alembic (миграции БД).
* **Архитектура данных:** Поддержка двух провайдеров доступа к БД (SQL + ORM).
* **Асинхронный обмен сообщениями:** Apache Kafka (отказоустойчивый кластер, топик `link-updates`, переключение транспорта через конфигурацию).
* **Контейнеризация:** Docker и Docker Compose.

### 2. Сервис Бота (`project-bot-service`)
Интерфейс взаимодействия с пользователем:
* **Платформа:** Telegram Bot API (асинхронный Python).
* **Взаимодействие:** Общение со скраппером через REST API клиент (`httpx`).
* **Управление состоянием:** Диалоговые сценарии, регистрация пользователей, отслеживание ссылок.

---

## 🚀 Ключевые реализованные возможности (Этапы разработки)

* **Этап 1-2 (Базовая логика и API):**
  * Создание REST API на FastAPI для регистрации пользователей и добавления ссылок.
  * Разработка Telegram-бота для управления подписками прямо из мессенджера.
* **Этап 3 (База данных и ORM):**
  * Подключение PostgreSQL, проектирование схемы данных.
  * Реализация миграций с помощью Alembic.
  * Абстракция хранилища с двумя провайдерами (прямые SQL-запросы и SQLAlchemy ORM).
* **Этап 4 (Тестирование и Качество кода):**
  * Покрытие кода юнит и интеграционными тестами (`pytest`, `pytest-cov`, HTML-отчеты о покрытии).
  * Настройка линтеров и форматтеров кода (`black`, `ruff`).
* **Этап 5 (Очереди сообщений и масштабирование):**
  * Интеграция асинхронной отправки уведомлений через Apache Kafka.
  * Настройка отказоустойчивого кластера Kafka и топиков.
  * Интеграционное тестирование с использованием Testcontainers.

## 🛠 Инструкция по запуску и тестированию

### Предварительные требования
* Python 3.13+
* Poetry / Pip
* Docker и Docker Compose (для запуска БД и Kafka)

### 1. Клонирование и настройка окружения
Перейдите в директорию соответствующего сервиса и установите зависимости:
```bash
# Для скраппера
cd project-scrapper-service
poetry install

# Для бота
cd ../project-bot-service
pip install -r requirements.txt
```

### 2. Запуск инфраструктуры через Docker
```bash
cd project-scrapper-service
docker compose up --build
```

### 3. Запуск сервисов
* **Запуск скраппера:**
  ```bash
  python -m uvicorn src.main:app --reload
  ```
* **Запуск бота** (предварительно указав токен в `.env`):
  ```bash
  cd ../project-bot-service
  python -m src.main
  ```

### 4. Запуск тестов и проверка линтером
```bash
# Тесты скраппера с отчетом о покрытии
pytest tests/ -v --cov=src --cov-report=html

# Проверка линтером (Ruff / Black)
ruff check --fix .
black .
```
